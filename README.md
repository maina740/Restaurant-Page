🍴 Restaurant App
A modern and responsive restaurant web application built using React, Redux Toolkit, and Material UI (MUI).
This project allows users to explore menu categories, view dish details, add/remove items to the cart, and manage orders with a clean UI.

🚀 Features
    Landing Page Sections
    Hero Section with intro banner
    Categories display
    Special Dishes (carousel with sliding cards)
    Culinary Services (2x2 service grid with text & images)
    Testimonials Section
    Footer with social links
Menu & Services
    MenuList page with dish cards
    ServicesDetail page showing service details in row layout with back navigation
Cart System
    Add/remove dishes from cart
    Increase/decrease item quantity with + / - buttons
    Clear entire cart
    Checkout button with action handler
    "Add More Dishes" button to go back to menu
Navigation
    Navbar with links to Home, Menu, Services, Cart
    Back button with arrow on detail pages
    Fully responsive

🛠️ Tech Stack
React.js (Frontend library)
Redux Toolkit (State management)
React Router (Page navigation)
Material UI (MUI) (UI components & styling)
